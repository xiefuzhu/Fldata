# Fldata

收到 ZIP 后，可按[交付说明](DISTRIBUTION.md)直接运行 Windows 版或从源码构建。

《数据结构（C语言版 · 第2版）》交互式学习工具，基于 Flutter。当前为 **Stage 0 完成 / Stage 1 组件 10/10 / Stage 2 12/12 / Stage 3 10/10 / Stage 4 8/8 / Stage 5 11/11 / Stage 6 8/8**。“逻辑结构与存储结构映射”“ADT Complex”“复杂度实验室”“顺序表”“单链表”“循环与双向链表”“线性表合并对比”、“多项式与图书”、“栈”、“递归”、“队列”和“栈队列案例”课程已开放，第 4 章串匹配实验室已开放 BF/KMP 双轨对比、前后缀制表推演和环串检测。数组与矩阵课程支持多维寻址、压缩存储和稀疏转置。广义表课程支持解析树、双存储视图及连续取头取尾。二叉树课程支持五条性质、欧拉环游、指针栈中序和队列层序。可按带 # 的先序串建树，或用先序/后序配合中序重构；复制、求深度与计数均可逐帧回放。中序线索树课程可逐步观察头结点、前驱与后继的连接，并沿线索完成无栈遍历。树与森林课程支持双亲表、孩子链表和孩子兄弟表示，可在同一画布上正放或倒放森林到二叉树的三步转换。哈夫曼实验可查看 HT 和编码表、输入明文并逐位译码。表达式树实验可回放双栈建树与后序求值。

> 第 6 章已开放「图的编辑与四种存储结构」。可载入 G₁、G₂、N 和 G₅，编辑图并逐边回放建表过程。「图的遍历、生成森林与六度空间」可用教材 G₄ 对照两种 DFS 与 BFS。在 30 人社区教学预设中，点击人物即可按最短路径逐层查看六度触达人数，也可切换到第 185 页的七次出队循环。「最小生成树」可在同一张无向网上切换 Prim 与 Kruskal，逐步对照割集、closedge、排序边表和分量号。「最短路径」可编辑教材 G₆，按表 6.4 逐轮查看 Dijkstra 的距离与前驱，并点击终点回溯路径。切换到 Floyd 可在同一张图上观察两段距离的拼接，或载入教材 G₇ 对照表 6.5 的四轮双矩阵。回放结束后，点击任一矩阵的单元即可查看该点对的路径。「拓扑排序与 AOE 关键路径」可逐弧查看入度和零入度栈，定位死锁回路，也可用图 6.28 正推与逆推事件时间，对照表 6.7 查看活动余量和两条并行关键路径。

> 第 7 章已开放「顺序、折半与分块查找」。可比较算法 7.1、7.2 的边界判断和关键字比较次数，在例 7.1 的判定树上查看查找路径与等概率 ASL，或用图 7.4 对照顺序索引和折半索引。记录表、块边界和目标值均可编辑。「二叉排序树」可复现图 7.5～7.10 的递归查找、插入、建树和删除。可对照两种插入顺序的树高与 ASL，逐帧查看双孩子结点的前驱替换，并在结果树上继续操作。切换到「AVL 插入」可沿父链观察 BF 更新，在最小不平衡子树处暂停，逐拍回放 LL、RR、LR、RL 旋转。「B-树与 B+树」可切换 3、4、5 阶，逐页查看分裂上推、借位、合并与根降高。B+树支持自定义闭区间，并沿叶链展示命中的记录。「散列表」支持构造散列函数、切换探测策略或链地址、回放删除和复用墓碑，并按关键字与初始地址分别推导成功和失败 ASL。

## 开发

已验证 Flutter **3.47.7** / Dart **3.13.5**，Windows Visual Studio C++ 工具链。命令在 Git Bash 执行：

    # 本机 SDK 路径，其他机器替换为自己的路径。
    export PATH="/c/Users/AndyYan/AGV/flutter-sdk/bin:$PATH"
    bash scripts/bootstrap_windows.sh
    flutter run -d windows

Bootstrap 在 Windows 缺少符号链接权限时为项目构建缓存创建 NTFS junction，需要 Node.js；不修改系统设置。依赖版本以 pubspec.lock 为准。计划中的 window_manager 0.7.0 / sprung 3.0.1 与本机 SDK 不兼容；采用 window_manager 0.5.2 和 Flutter SpringSimulation；drift_dev 使用实际已发布的 2.35.3。字体许可见 assets/fonts/OFL.txt。

## 数据约定

- 数据库由 path_provider 的应用支持目录持久化，界面通过 Riverpod → Repository 访问。
- 备份扩展名 .fldata.json；schemaVersion=1；payload 包含全部八表。行字段采用 SQLite 列名，时间为 UTC Unix 秒。
- 合并：实验状态取较高者，学习时长相加，同日统计取较大值；同名模块数据集去重；答题流水按全部业务字段去重；草稿按更新时间保留。错题因 v1 无复习更新时间，采用较早的待复习日期。缓存掌握度按已安装课程总数重算。
- **重复合并同一备份会再次增加学习时长**。设置页在读取备份后提供合并和覆盖本机记录两种选择。
- DailyStudyStats 增加 studySeconds，避免短学习片段在分钟换算时丢失。
- Android 通过 `MainActivity` 的 `WindowCompat.enableEdgeToEdge(window)` 配置系统栏，并在清单中开启预测性返回。
