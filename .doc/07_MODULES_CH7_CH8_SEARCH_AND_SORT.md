## 一、第 7 章：查找 (`lib/curriculum/ch7_search/`)

### 7.1 `ch7_linear_bin_block` — 顺序哨兵、折半判定树与分块查找（算法 7.1～7.3）
- **1-indexed 哨兵规范**：顺序查找统一将 `ST.R[0]` 隔在最左侧绘为紫色虚线 **`R[0] 监视哨`** 槽位。演示算法 7.2 查找前先将目标值 `key` 填入 `ST.R[0].key`，随后游标 `i` 从表尾 `length` 倒推时省去每次判断 `i >= 1`，哪怕查找失败也必在 `i == 0` 停住返回 `0`。与算法 7.1（无哨兵每次双条件判断）对比语句执行频度。
- **折半查找双联视图（算法 7.3 `Search_Bin`）**：
  - 上半区展示有序表 `R[1..length]`、`low/mid/high` 三枚指针与动态收缩的有效搜索区域遮罩；
  - 下半区**同步绘制完整折半查找判定树（严格按 `mid = ⌊(low+high)/2⌋` 切分，若为偶数长度左子树少 1 个或右子树多 1 个，内部成功节点画实心圆，叶子下挂正方形失败节点 `□`）**；
  - 右侧实时列出成功与失败 $ASL$ 计算过程：$ASL_{\text{succ}} = \frac{1}{n}\sum (\text{深度}_i)$，$ASL_{\text{unsucc}} = \frac{1}{n+1}\sum (\text{失败层数}-1)$。
- **分块查找（索引顺序查找）**：双层数组联动——上方「索引表（存每块最大关键字 + 起始下标）」（可选顺序或折半定位块）→ 下方「块内无序、块间有序子表」顺序扫描。

### 7.2 `ch7_bst_avl_lab` — BST 增删与 AVL 平衡二叉树四种物理旋转（算法 7.4～7.7）
- **二叉排序树 BST（算法 7.4～7.7）**：
  - 支持对比演示「序列 `[45, 24, 53, 45*, 12, 24*]`（均衡）vs 有序序列 `[12, 24, 37, 45, 53]`（退化成高 $n$ 单支斜树 $ASL = (n+1)/2$）」。
  - **算法 7.7 `DeleteBST` 三种情形细化动画**：
    1. 被删节点 `p` 为叶子：直接断开双亲指针释放 `delete p`；
    2. `p` 只有左子树或只有右子树：绘制一条弧线令唯一孩子直接“子承父业”重接到 `p` 的双亲；
    3. `p` 左右子树均不空（核心难点）：高亮找 `p` **左子树的最右下节点 `s`（即中序直接前驱）**，演示两步动作——用 `s->data` 替换 `p->data`，然后将其左孩子 `s->lchild` 嫁接到 `q->rchild`（若 `q == p` 则接到 `q->lchild`）并释放 `s`。
- **平衡二叉树 AVL 实验室**：
  - 每个节点右上角实时计算并显示动态平衡因子角标 **`BF = height(L) - height(R) ∈ {-1, 0, +1}`**；
  - 插入新节点后沿父链自底向上逐个刷新 `BF`，一旦发现第一个 `|BF| == 2` 祖先 `A`：
    1. 立即暂停并用橙色虚线框出**最小不平衡子树**，识别并高亮失衡类型徽章 **`LL / RR / LR / RL`**；
    2. 按教材指针变换执行 **物理弹簧旋转**：
       - **LL 型（右单旋）**：`B`（`A` 左孩）提为新根，`A` 降为 `B` 右孩，原 `B` 右子树 `BR` 挂接为 `A` 左子树；
       - **RR 型（左单旋）**：`B`（`A` 右孩）提为新根，`A` 降为 `B` 左孩，原 `BL` 挂接为 `A` 右子树；
       - **LR 型（先左后右双旋）** & **RL 型（先右后左双旋）**：严格拆解为**两拍独立旋转帧**（先旋转子层形成 LL/RR，短暂停顿展示中间件状态，再旋转 `A` 恢复整体平衡！），使 `Reingold-Tilford` 驱动整棵子树刚体滑移一目了然。

### 7.3 `ch7_btree_bplustree` — `m` 阶 B-树分裂/合并与 B+树（算法 7.8～7.9）
- **配置参数**：支持下拉设置阶数 $m \in \{3, 4, 5\}$，实时在顶部提示约束阈值「关键字个数范围：非根内部节点 $\lceil m/2 \rceil - 1 \le k \le m - 1$」。
- **插入分裂动画（算法 7.9）**：多关键字槽渲染节点 `[n | P0 | K1 | P1 | ...]`。当插入导致节点关键字数达到 $m$ 溢出时，在中间位置 $s = \lceil m/2 \rceil$ 闪烁劈裂线：$K_s$ 向上漂浮并入双亲节点，左半部 $[1..s-1]$ 与右半部 $[s+1..m]$ 向两侧弹开成两个兄弟节点，支持触发连续级联向上分裂直至创建更高一层新根节点！
- **删除下溢调节动画**：删掉关键字后若剩余数 $< \lceil m/2 \rceil - 1$，依次动画演示「左/右兄弟富余 → 父亲下沉、兄弟上提的**父子借位旋转**」与「两侧兄弟均贫穷 → 与父夹缝关键字向下**三合一合并**」导致树高减 1。
- **B+树模式**：展示非叶节点仅存索引副本、所有真实数据指针与记录集中在最底层并用紫色横箭串联成的**顺序叶链表**，支持输入 `[lowKey, highKey]` 演示顺叶链表快速区间范围扫描。

### 7.4 `ch7_hash_table` — 散列构造、碰撞处理与 `ASL` 自动推导（算法 7.10）
- **4 种散列函数实验**：除留余数法 `H(key) = key % p`（默认 `p ≤ m`）、直接定址法、数字分析法、平方取中/折叠法。
- **开放地址法（算法 7.10）vs 链地址法对比**：
  - 开放地址支持切换 **线性探测**（$d_i = 1, 2, \dots$，直观标出「二次聚集/堆积」连片橙色块）、**二次探测**（$d_i = +1^2, -1^2, +2^2, -2^2 \dots$）与 **伪随机探测**；
  - **墓碑删除机制专题提示**：执行开放地址删除操作时，被删槽位绝不简单清空为 `NULL`，而是放置一枚灰紫 **`DELETED` 墓碑图标**，演示后续查找链遇墓碑仍继续向后探测而插入可复用该槽位。
- **易错公式自动剖析**：右侧面板逐个列出表内元素的探测次数及 $ASL_{\text{succ}}$，并重点针对 **$ASL_{\text{unsucc}}$ 的分母取散列函数模数 `p`（所有可能散列地址 `0..p-1` 的各自走到空位探测次数之和除以 `p`）而非表长 `m`** 的经典教材考点给出逐地址推导明细表！

## 二、第 8 章：排序与竞速擂台 (`lib/curriculum/ch8_sort/`)

### 8.1 全章统一渲染规范（严格对齐严蔚敏教材）
1. **1-indexed `SqList.r[1..length]`**：`r[0]` 专作紫罗兰虚线 **监视哨 / 快排枢轴暂存槽**；
2. **稳定性可视化角标（必做亮点）**：输入序列如教材经典序列 `[49, 38, 65, 97, 76, 13, 27, 49]` 中存在相同关键字时，自动给第 1 个标记为 `49`、第 2 个加上醒目星号角标 `49*`（或不同色彩左下圆点）。排序结束后若出现 `49*` 跑到 `49` 前面，右侧立即亮起红色 **`不稳定 (Unstable)`** 徽章及发生跨位交换的关键帧定位链接！
3. 全程自动累计 **`KCN`（关键字比较次数）**、**`RMN`（记录移动次数）** 及递归栈空间。

### 8.2 五大排序实验模块详解
1. **`ch8_insert_shell`（算法 8.1～8.3）**：
   - **8.1 直接插入**：将待插 `r[i]` 飞跃放入 **`r[0]` 监视哨**，然后 `r[j]` 向后移位直至 `r[0].key >= r[j].key` 后落回 `r[j+1]`；左侧区绿色遮罩标识「有序区 `1..i-1`」；
   - **8.2 折半插入**：保留 `r[0]` 暂存后，改用 `low/mid/high` 二分查找快速定位最终插入点，再一次性整体后移 `j = i-1 .. high+1`（对比直接插入明显减少了 `KCN`，但 `RMN` 相同）；
   - **8.3 希尔排序**：按当前增量 `dk`（默认序列 `[5, 3, 1]`，可自定义）用相同颜色的顶部拱线连接同组元素 `[i, i+dk, i+2dk...]`，展示每趟分组插排快速令序列趋于「基本有序」。
2. **`ch8_swap_bubble_quick`（算法 8.4～8.5）**：
   - **8.4 冒泡排序**：支持开启 `flag` 提前终止开关，一旦整趟 `m` 到 `1` 未发生交换立即结束；
   - **8.5 快速排序（原汁原味挖坑填数法）**：`Partition` 开始先把 `r[low]` 吊装进 **`r[0]` 枢轴暂存区**，原本 `low` 槽留出一个虚线空坑；随后 `high` 向左扫描遇到 `< pivotkey` 的记录将其抛物线飞填入 `low` 坑（`high` 变成新坑），接着 `low` 向右找 `> pivotkey` 填入 `high` 坑……直到 `low == high` 将 `r[0]` 枢轴落回正中央！下方同步生长**快排递归区间树**直观体现最优 $O(\log_2 n)$ 与最坏有序退化 $O(n)$ 栈深对比。
3. **`ch8_select_heap`（算法 8.6～8.9）**：
   - **8.6 简单选择** & **树形选择排序（锦标赛树）**（直观展示填 `∞` 胜者晋级思想如何启发堆排序将空间降为 $O(1)$）；
   - **8.7～8.9 堆排序（数组 × 完全二叉树双生同步）**：上半画布画标准完全二叉树，下半画布画对应一维数组 `r[1..n]`（高亮 `parent=s` 与左右孩 `2s, 2s+1` 连线）。分两大阶段呈现：`① CreatHeap` 从最后一个非叶节点 `⌊n/2⌋` 倒序到 `1` 逐个向下 `HeapAdjust` 建大根堆；`②` 循环 `n-1` 次将堆顶 `r[1]` 与当前末尾 `r[i]` 跨视图抛物线对换、堆规模缩减 1、再自顶向下筛稳。
4. **`ch8_merge_radix_race`（算法 8.10～8.12 + 竞速擂台）**：
   - **8.10～8.11 2-路归并排序**：分治树拆分展示 + 下方并排开辟辅助数组 `TR[]` 双指针 `i, j, k` 顺序拾取归并后再回写原表；
   - **8.12 链式基数排序**：展示静态链表 `r[0..n]`（带 `next` 游标指针字段）与底部 **10 个队列桶（`0..9` 各含头指针 `f[i]`、尾指针 `e[i]`）**；按个位→十位→百位逐趟执行 **`Distribute`（顺序拆链挂入对应数字桶尾）** 与 **`Collect`（将非空桶首尾指针串联成一条新链表）** 的零关键字比较排序过程！
   - **`SortRaceArena` 多算法同屏竞速擂台**：允许用户任意勾选 2～4 种内排算法（如 `快速排序 vs 堆排序 vs 希尔排序 vs 直接插入`），在完全相同的「随机 / 正序 / 逆序 / 大量重复」样本集上同时启动节拍器竞速，结尾弹出复刻教材 **表 8.2**（所附第 2 版第 267 页）的时空/稳定性横向排行战报。
5. **`ch8_external_sort`（第 8.7 节 外部排序三大机制全景模拟）**：
   - **① `k` 路平衡归并败者树 `LoserTree`**：支持 $k = 5$ 路输入顺串归并，上方绘制完全二叉树状败者树 `ls[0..k-1]`（内部节点记录败者顺串号，最高顶冠军框 `ls[0]` 存入当前全局最小者），下面列出 `k+1` 长度外结点缓冲 `b[0..k]`（`b[k]` 放 `MINKEY` 初值哨兵）。每次输出 `b[ls[0]]` 进写磁盘输出段后，该路读入下一元素，动画沿父指针 `t = (s + k) ~/ 2` 向上一路与各层老败者较量（**败者留父、胜者续攀**）刷新 `ls[0]`！
   - **② 置换-选择排序**：内存工作区 `WA[w]`（默认容量 `w = 6`）不断吞吐无序外存大文件记录并利用迷你败者树挑选不小于上一输出 `MINIMAX` 的最小元素吐出（否则冻结标记为下一归并段），直观验证生成的初始顺串平均长度可拉长至 `2w`！
   - **③ 最佳归并树与虚段补全**：输入 $m$ 个不等长初始归并段权值与归并路数 $k$，自动判别 $(m - 1) \bmod (k - 1)$ 是否为 `0`，若非 `0` 自动在桌面弹出并补足 `u = k - 1 - ((m - 1) % (k - 1))` 个 **`0` 权值虚段（虚线灰圆节点）** 后构建 $k$ 叉哈夫曼归并树，计算并显示外存读写总次数 $= 2 \times WPL$。
