## 一、第 4 章：串、数组和广义表 (`lib/curriculum/ch4_string_array_glist/`)

### 4.1 `ch4_bf_kmp_lab` — BF vs KMP 双轨对比、`next/nextval` 显微镜与环状病毒 DNA（算法 4.1～4.5）
- **教材下标约定（关键！）**：严蔚敏教材定长串 `SString` 使用 **1-indexed**（`ch[0]` 存长度或不用，字符从 `ch[1]` 到 `ch[length]`）。画布在下标 `[0]` 处用紫色胶囊渲染 `len = m`，字符槽从 `[1]` 开始编号。
- **三大子模式详解**：
  1. **模式 A：BF（算法 4.1 `Index_BF`）与 KMP（算法 4.2 `Index_KMP`）同屏双轨对比**
     - 上下两条轨道同时对同一对 `(S, T)` 执行匹配（默认教材原题：`S = "ababcabcacbab"`, `T = "abcac"`，匹配成功返回位置 `6`）。
     - 每当发生失配（`S[i] != T[j]`）：
       - 上轨 BF 绘制红色大弯弧箭头将 `i` 剧烈回溯到 `i - j + 2`、`j` 退回 `1`，模式串仅右移 1 格；
       - 下轨 KMP **主串指针 `i` 纹丝不动（加锁图标高亮！）**，读取 `next[j]`（或切换为 `nextval[j]`），模式串标尺整条平滑滑动向右对齐 `T[next[j]]` 与 `S[i]`，并用绿色高亮底纹覆盖已验证相等的前缀 `T[1..next[j]-1]`，直击 KMP 避免主串回溯的本质。
  2. **模式 B：`get_next`（算法 4.3）与 `get_nextval`（算法 4.4）递推显微镜**
     - 对称底纹匹配：计算 `next[j]` 时，用绿色框标出当前模式串前段真前缀 `T[1..k-1]`，用蓝色框标出紧邻 `j` 左侧的等长真后缀 `T[j-k+1..j-1]`；当 `T[i] != T[j]` 时，动画演示 `j = next[j]` 跳向更短前/后缀的迭代退却，并在 `nextval` 轨道演示“若 `T[next[j]] == T[j]`，提前一路继承 `nextval[next[j]]`”的一步跳过效果。
     - **教材单测标准基准数据（`1-indexed`）**：
       - 模式串 `'abaabcac'`（长度 8）：
         `next    = [0, 1, 1, 2, 2, 3, 1, 2]`（即 `j=1..8` 分别为 `0, 1, 1, 2, 2, 3, 1, 2`）
         `nextval = [0, 1, 0, 2, 1, 3, 0, 2]`
       - 模式串 `'aaaab'`（长度 5）：
         `next    = [0, 1, 2, 3, 4]`
         `nextval = [0, 0, 0, 0, 4]`（高亮连续 4 个 `0`，展示失配直接整体跨越！）
  3. **模式 C：案例 4.1 环状病毒感染检测（算法 4.5）**
     - 给出人类 DNA 长链与环形病毒 DNA（如 `"baa"` 长度 $m=3$）。先绘制环形首尾相接病毒链，随后剪开并**复制倍增拼接成 $2m$ 线性串 `"baabaa"`**，用长度 $m$ 的滑动窗口依次切出 `"baa"`, `"aab"`, `"aba"` 全部 $m$ 种旋转子串调用 KMP 匹配人体 DNA。

### 4.2 `ch4_array_matrix` — 多维数组寻址、特殊矩阵压缩与三元组快速转置
- **二维/三维数组寻址动画**：支持输入行/列维数 $(m, n)$ 与基址 `LOC(0,0)`、元素字节大小 `L`，一键切换 **行主序（C/C++：`LOC(i,j) = LOC(0,0) + (i*n + j)*L`）** vs **列主序（Fortran：`LOC(i,j) = LOC(0,0) + (j*m + i)*L`）**，鼠标点击方阵任意单元格 `a[i][j]`，动画沿行（或列）扫过前面的所有单元格后连线至右侧线性内存条唯一地址槽。
- **特殊矩阵压缩交互**：
  - **对称矩阵 & 下三角矩阵**（按行序压缩进 $n(n+1)/2$ 一维数组 `sa[0..k]`）：下三角按 $k = \frac{i(i-1)}{2} + j - 1$ 映射（$1$-indexed 矩阵到 $0$-indexed 一维数组），对称矩阵点击上三角元素 $(i < j)$ 自动高亮其对称转置下三角位置 $(j, i)$；三角矩阵末尾追加 `[n(n+1)/2]` 常数 `c` 公共槽。
  - **三对角带状矩阵**（$a_{1,1}$ 到 $a_{n,n}$ 仅主对角线与上下相邻两对角线非零）：映射 $k = 2i + j - 3$，点击带外零元素提示落入公共常数零区。
- **稀疏矩阵三元组表 `TSMatrix` 快速转置 (`FastTransposeSMatrix`)**：同步渲染 `num[col]`（各列非零元个数）与 `cpot[col] = cpot[col-1] + num[col-1]`（各列第一个非零元在新三元组中的起始存放下标），演示一次扫描原三元组直接定位写入新三元组对应下标的过程，并与传统双重循环转置 $O(nu \cdot tu)$ 对比步数。

### 4.3 `ch4_glist_explorer` — 广义表拆解器与双存储视图
- 支持输入任意带括号嵌套表达式如 `D = (E, (a), (b, (c, d)))` 与空表 `()`。自动构建解析树并计算显示 `GetLength(L)` 与 `GetDepth(L)`（原子深度 $0$、空表深度 $1$、嵌套表 $1 + \max(\text{子表深度})$）。
- 提供 **`GetHead(L)`（取表头）** 与 **`GetTail(L)`（取表尾，必为加括号的列表！）** 连续交互按钮，每点一次高亮剥离结果并允许切换「头尾链表存储（`tag=0` 原子 / `tag=1` 表节点 `hp, tp`）」与「扩展线性链表存储」。

## 二、第 5 章：树和二叉树 (`lib/curriculum/ch5_tree/`)

### 5.1 `ch5_bitree_traverse` — 二叉树性质、欧拉环游与遍历重建（算法 5.1～5.6）
- **教材锚点**：5.3 节二叉树 5 条基本性质；5.4 节顺序存储（补 `'#'`/`0` 映射完全二叉树下标 $2i, 2i+1$）vs 二叉链表；**算法 5.1** 递归先/中/后序遍历；**算法 5.2** 中序非递归栈遍历；层序队列遍历；**算法 5.3** 含 `'#'` 先序序列建树（如 `"ABC##DE#G##F###"`）；**算法 5.4～5.6** 复制树、求树深、统计节点总数的递归微步。
- **核心动画设计详解**：
  1. **教材图 5.11 欧拉环游轮廓轨迹仪**：渲染包围整棵二叉树节点的平滑圆弧外轮廓路径。一个发光小球从根左侧出发，逆时针贴着树形轮廓滑行一圈（每个节点恰好经过**左切点 1 次、底切点 1 次、右切点 1 次**）：
     - 切换「先序」：球每擦过节点**左侧切点**瞬间发出声光脉冲，将节点值收入下方输出序列；
     - 切换「中序」：仅在经过**底部切点**时采集；
     - 切换「后序」：仅在经过**右侧切点**时采集。一图彻底打通三种遍历的统一几何直觉！
  2. **非递归遍历（算法 5.2）**：右侧同步挂出 `SqStack<BiTree>` 指针栈，清晰展示指针 `p` 一路向左下 `Push` 滑到底直到 `p == NULL`，然后 `Pop` 出栈访问并转向右子树 `p = q->rchild` 的真实栈帧变化。
  3. **序列重构二叉树工作室**：支持输入任意合法「先序 + 中序」或「后序 + 中序」序列（如先 `ABDGCEF` + 中 `DGBAECF`），分步动画演示由先序首元素定位中序分割点、在序列下方竖起左右区间分隔线、并递归在画布上长出左右子树的全过程。

### 5.2 `ch5_threaded_tree` — 中序线索二叉树（算法 5.7～5.9）
- **教材锚点**：节点五元组 `BiThrNode{lchild, LTag, data, RTag, rchild}`；算法 5.7 `InThreading`；算法 5.8 带头节点 `Thrt` 中序线索化 `InOrderThreading`；算法 5.9 `InOrderTraverse_Thr`。
- **关键帧亮点**：
  - 画布节点渲染为宽盒 `[LTag | lchild | data | rchild | RTag]`，实心箭头代表孩子（`Tag=0`），**紫色虚线带弧度曲线代表线索（`Tag=1`）**；
  - 全局追踪指针 `pre` 徽章紧随 `p` 移动，每遇到 `p->lchild == NULL` 立刻翻转 `LTag=1` 并将左空域虚线连向 `pre`；遇到 `pre->rchild == NULL` 翻转 `RTag=1` 将前驱的右空域虚线连向当前 `p`；最终头节点 `Thrt` 形成完美首尾双向闭环。
  - 遍历模式（算法 5.9）演示**栈深度恒为 `0`**，仅靠 `while (p != T)` 沿着最左下找到首节点，然后根据 `RTag == 1` 顺藤摸瓜虚线直达后继，实现 $O(1)$ 辅助空间遍历。

### 5.3 `ch5_tree_forest_conv` — 树、森林与二叉树的互转（孩子兄弟法 45° 旋转）
- **教材锚点**：5.6 节双亲表示法 `PTree`、孩子链表、`CSTree` 孩子兄弟二叉链表；树/森林与二叉树的相互转换及对应遍历关系（树的先根/后根 ↔ 二叉树先序/中序；森林先序/中序 ↔ 二叉树先序/中序）。
- **核心几何变换插值（三拍连续弹簧动画）**：
  1. **Step 1（加线）**：在森林或树的所有相邻兄弟节点之间生长出一条水平金色连线，并把多棵树的根节点横向用金线连成兄弟；
  2. **Step 2（去线）**：对每个节点，仅保留它与**第一个孩子（长子）**之间的父子连线，其余向次子、三子的连线渐隐断开；
  3. **Step 3（旋转 45° 层次化）**：计算所有节点的目标二叉树坐标 `(x_bin, y_bin)`（左斜指向长子、右斜指向右兄弟），由 `Reingold-Tilford` 插值平滑摆正为标准二叉树！点击「还原为森林」可逆向倒放三拍动画恢复多叉森林结构。

### 5.4 `ch5_huffman_expr` — 哈夫曼编码压缩（算法 5.10～5.11） & 表达式树（算法 5.12～5.13）
- **哈夫曼树构造与编解码器（案例 5.1）**：
  - 默认载入教材经典 8 字符权重表 `{5, 29, 7, 8, 14, 23, 3, 11}`（教材第 139 页例 5.2，$WPL = 271$，树高为 5 层），左侧联动渲染严蔚敏教材定义的一维静态三叉表 **`HT[1..2n-1]`（含 `weight, parent, lchild, rchild` 列）**。
  - 每轮用琥珀色高亮所有 `parent == 0` 候选行，挑出最小两权值 `s1, s2`，在上方森林画布中浮起合成新双亲节点写入 `HT[i]`，同步更新 `parent` 字段并在右上角动态累加路径权重和 `WPL`。
  - **算法 5.11 编码表与实战压缩**：树建成后从叶子逆推回根生成每字符 `0/1` 前缀编码，提供输入框让用户键入明文字符串即时编码为 `01` 比特流、统计相比定长编码的压缩率，并点击「逐位走树译码」让光标从根节点按 `0左/1右` 走至叶节点逐个吐出明文字符。
- **案例 5.2 表达式二叉树（算法 5.12～5.13）**：
  - 输入 `"3*(7-2)#"`，展示运算符栈 `OPTR` 与**二叉树根节点栈 `EXPT`** 协同工作：遇到数字创建单叶节点压入 `EXPT`；表 3.1 判定 `>` 时弹出算符 $\theta$ 与两棵子树 `a, b` 组合成一棵新子树再压回 `EXPT`；最终后序递归遍历该树（算法 5.13 `EvaluateExpTree`）算出结果 `15`。
