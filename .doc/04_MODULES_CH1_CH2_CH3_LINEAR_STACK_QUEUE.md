## 一、第 1 章：绪论 (`lib/curriculum/ch1_intro/`)

### 1.1 `ch1_struct_mapping` — 逻辑结构与存储结构映射器（例 1.1～1.3）
- **教材锚点**：1.1 节例 1.1（学生学籍表—线性）、例 1.2（人机对弈井字棋树—树形）、例 1.3（城市交通网—图形）；1.2 节 4 种逻辑结构 × 2 种物理存储结构（顺序存储 vs 链式存储）。
- **交互与关键帧**：
  1. 左侧提供 4 个分段按钮：`集合` / `线性(学籍表)` / `树形(井字棋博弈树)` / `图形(交通网)`；顶部提供存储切换：`顺序存储` / `链式存储`。
  2. 右侧实时渲染「计算机一维物理内存条 `0x2000..0x2040`」：切换至「顺序存储」时，节点按下标紧挨着填入连续内存格，展示基址计算 $LOC(a_i) = LOC(a_1) + (i-1) \times l$；切换至「链式存储」时，节点散落分布在随机空闲内存格中，通过指针地址字段与弯曲箭头还原逻辑拓扑关系。点击左侧任意逻辑节点，右侧物理内存槽立即高亮闪烁。

### 1.2 `ch1_adt_complex` — 抽象数据类型 `ADT Complex` 实验室
- **教材锚点**：1.3 节复数 `ADT Complex = (D, S, P)` 定义与 `Creat/GetReal/GetImag/Add/Sub/Multiply/Divide` 类C实现。
- **交互与关键帧**：左侧展示三元组抽象黑盒封装边界，右侧双视图同步：上半部分绘制复平面直角坐标系向量 $Z_1, Z_2$ 的平行四边形相加或极角相加相乘动画；下半部分跟踪 `void Add(Complex A, Complex B, Complex &C)` 中引用参数 `&C` 如何直接修改调用方内存结构体成员 `realpart` 与 `imagpart`。

### 1.3 `ch1_complexity_lab` — 语句频度热力计与渐近复杂度曲线仪
- **教材锚点**：1.4 节例 1.4（$n$ 阶矩阵相乘 $O(n^3)$）、例 1.5～1.9（常数阶/线性阶/平方阶/对数阶 `i=i*2` 频度推导）、图 1.7（7 种数量级函数增长趋势对比）、例 1.10（顺序查找最好 $1$ / 最坏 $n$ / 平均 $(n+1)/2$）、例 1.11（数组原地逆序 $S(n)=O(1)$ vs 辅助数组逆序 $S(n)=O(n)$）。
- **交互与关键帧**：
  1. **曲线实验室**：拖动滑块调整问题规模 $n \in [1, 32]$，实时用 `CustomPainter` 绘制 $1, \log_2 n, n, n\log_2 n, n^2, n^3, 2^n$ 七条色彩曲线，悬停任意 $n$ 显示具体操作步数（$n=20$ 时直观警告 $2^{20} = 1,048,576$ 爆炸增长）。
  2. **逐行语句频度热力计**：切换运行例 1.4～1.9 代码，实时播放每层循环并统计每行代码执行次数，在代码行右侧渲染按频度比例伸缩的横向热力条（例 1.4 展示外层 $n$、中层 $n^2$、内层核心乘法句 $n^3$）。
  3. **时空对比 mode（例 1.11）**：同屏对比两种逆序算法——上方只额外申请 1 个紫罗兰色临时变量 `t`（原地双指针 `i++, j--` 对换），下方弹出完整副本数组 `b[n]`。

## 二、第 2 章：线性表 (`lib/curriculum/ch2_linear_list/`)

### 2.1 `ch2_sqlist_ops` — 顺序表基本操作与期望移动分析（算法 2.1～2.5）
- **教材锚点**：`SqList{ElemType *elem; int length;}`（`0-indexed`），算法 2.1 `InitList_Sq`、2.2 `GetElem`（$O(1)$ 随机存取）、2.3 `LocateElem_Sq`（顺序查找 $ASL = \frac{n+1}{2}$）、2.4 `ListInsert_Sq`、2.5 `ListDelete_Sq`。
- **关键帧脚本与边界**：
  - **随机存取展示**：执行 `GetElem(L, i, e)` 时，直接高亮首地址偏移公式 `elem + (i - 1) * sizeof(ElemType)` 一步直达，强化顺序表 $O(1)$ 特性。
  - **插入（算法 2.4）**：`i` 合法范围 $[1, L.length+1]$。合法时，先从最末尾下标 $j = L.length-1$ 逆序逐一往后挪一格（`L.elem[j+1] = L.elem[j]`），用抛物线微弧展示元素右移避免覆盖；移空位后将新元素落入 `L.elem[i-1]`，`length++`。同步弹出理论期望值徽章 $E_{\text{ins}} = \frac{n}{2}$。
  - **异常边界**：专门预设按钮「插入位置 $i = length+2$ 或 $i=0$（触发 `ERROR`）」「表满插入（触发 `OVERFLOW`）」，高亮校验判断分支并弹出红色异常状态徽章。

### 2.2 `ch2_linklist_ops` — 单链表基本操作与「错误断链」反例沙盒（算法 2.6～2.12）
- **教材锚点**：`LNode{ElemType data; struct LNode *next;}`，算法 2.6 `InitList_L`、2.7 `GetElem_L`、2.8 `LocateElem_L`、2.9 `ListInsert_L`、2.10 `ListDelete_L`、2.11 `CreateList_H`（前插法逆序）、2.12 `CreateList_R`（后插法正序）。
- **核心设计解答（教学痛点全覆盖）**：
  1. **「带头节点 vs 不带头节点」实时对比开关**：切换开关后，执行头端（$i=1$）插入/删除，直观对比带头节点下 `p` 从头节点 `L` 出发统一处理，而不带头节点必须单写 `if (i == 1)` 修改头指针 `L` 的繁琐。
  2. **算法 2.9 指针重连两拍慢放 & 错误反例按钮**：
     - 正常顺序：`① s->next = p->next;`（先画一条蓝色曲线从 `s` 连向 `p` 原后继，确保后半段不断链） → `② p->next = s;`（再将 `p` 的 `next` 箭头磁吸改接到 `s`）。
     - **「演示误序断链（⚠️ 反例）」按钮**：故意先执行 `p->next = s;`，触发引擎 `detectMemoryLeaks()` 立即将原有 `a_i..a_n` 整段节点标红闪烁，弹出提示 `"严重错误：p->next 已被覆盖，原后续链表永久失联导致内存泄漏，下一步 s->next = p->next 将形成自环！"`。
  3. **前插法（2.11）vs 后插法（2.12）**：输入 `'A','B','C','D'`，动画呈现前插法永远插在头节点 `L` 之后导致最终链序反转为 `D->C->B->A`，而后插法依靠尾指针 `r` 同步后移保持 `A->B->C->D` 原序。

### 2.3 `ch2_circular_dulink` — 循环链表 `O(1)` 合并与双向链表四指针手术（算法 2.13～2.14）
- **教材锚点**：2.5.3 仅设尾指针 `Ta, Tb` 的单循环链表 $O(1)$ 合并；2.5.4 双向链表 `DuLNode{data, *prior, *next}` 算法 2.13 `ListInsert_DuL` 与 2.14 `ListDelete_DuL`。
- **关键帧要点**：
  - **尾指针合并循环链表**：展示 `p = Ta->next; Ta->next = Tb->next->next; delete Tb->next; Tb->next = p;` 四步逐帧动画——突出为何只需要尾指针就能 $O(1)$ 同时定位两个表头和表尾并释放 `Tb` 冗余头节点。
  - **双向链表插入（算法 2.13）**：双端端口连线严守教材四步顺序（`① s->prior = p->prior;` → `② p->prior->next = s;` → `③ s->next = p;` → `④ p->prior = s;`），高亮展示为何 `②` 必须在 `④` 之前（否则 `p->prior` 丢失无法找回前驱！）。

### 2.4 `ch2_merge_compare` — 线性表合并对比与原地穿针归并（算法 2.15～2.17）
- **教材锚点**：表 2.2 / 2.3 顺序表 vs 链表时空性能对照卡片；算法 2.15 无序表并集 `MergeList`（$O(m \cdot n)$）；算法 2.16 顺序有序表归并 `MergeList_Sq`（开辟新数组 `LC`）；算法 2.17 链式有序表合并 `MergeList_L`（复用节点原地归并）。
- **关键帧要点**：算法 2.17 用 `pa, pb, pc` 三个指针徽章同时沿 `LA, LB` 向右滑行，每次比较 `pa->data <= pb->data` 后直接把胜出节点通过 `pc->next = pa` 穿接到结果链上，最后将剩余非空半截链直接 `pc->next = pa ? pa : pb` 整串挂接并 `delete Lb` 头节点——直观体现**额外空间复杂度 $O(1)$**。

### 2.5 `ch2_cases_polyn_book` — 稀疏多项式相加与图书信息管理系统（案例 2.1～2.3）
- **教材锚点**：案例 2.1 稠密多项式数组浪费空间警示；案例 2.2 稀疏多项式 `PNode{coef, expn, *next}`（**算法 2.18 `CreatePolyn` 按指数升序建表** + **算法 2.19 `AddPolyn` 多项式相加**）；案例 2.3 图书表顺序/链式实现增删查。
- **关键帧要点（算法 2.19 经典难点）**：预设多项式 $P_A(x) = 7 + 3x + 9x^8 + 5x^{17}$ 与 $P_B(x) = 8x + 22x^7 - 9x^8$。重点呈现指数相等（`p1->expn == p2->expn`）的分支：当 `+9x^8` 与 `-9x^8` 相加得 `sum == 0.0` 时，`r = p1; p1 = p1->next; delete r; r = p2; p2 = p2->next; delete r;` **同时销毁两个节点**的干净动画！

## 三、第 3 章：栈和队列 (`lib/curriculum/ch3_stack_queue/`)

### 3.1 `ch3_stack_sq_link` — 顺序栈、无头节点链栈与共享双栈（算法 3.1～3.8）
- **教材锚点**：`SqStack{SElemType *base; SElemType *top; int stacksize;}`（算法 3.1～3.4 `Init/Push/Pop/GetTop`）；链栈 `LinkStack` **无头节点**（算法 3.5～3.8）；习题共享数组双栈 `DblStack`。
- **核心设计细节**：
  - **教材 pointer 约定精讲**：顺序栈 `S.top` **始终指向栈顶元素的下一个空位置**。动画中竖向绘制内存桶，`base` 锚定底部，`top` 锚定当前空槽。
    - **入栈 (`Push`)** 两微步：`① *S.top = e`（写入当前 `top` 所指空槽）→ `② S.top++`（`top` 指针上移一格），判满条件为 `S.top - S.base == S.stacksize`。
    - **出栈 (`Pop`)** 两微步：`① --S.top`（`top` 指针先下移回栈顶有效元素）→ `② e = *S.top`（读出数据，槽位变灰标记为已释放）。
  - **链栈（无头节点）**：栈顶指针 `S` 直接指向首元节点，`Push` 时 `p->next = S; S = p;` 压入链表最左侧。

### 3.2 `ch3_recursion_hanoi` — 栈与递归工作机制（算法 3.9～3.10 汉诺塔 & 图 3.10/3.11）
- **教材锚点**：3.3 节 `Fact(n)`、`Fib(n)`、算法 3.9 递归输出单链表 `TraverseList`、算法 3.10 `Hanoi(n, A, B, C)`、图 3.10/3.11 递归工作栈活动记录机制。
- **三视图强同步设计**：
  1. **物理舞台（左上）**：`A, B, C` 三根柱子与 `n (1..6)` 个彩色圆盘平滑抛物线搬移（`move(A, n, C)`），严防大盘压小盘。
  2. **系统递归工作栈面板（右侧）**：复刻教材图 3.10/3.11，每一帧严格渲染活动记录压栈/弹栈，字段包含 `[返回地址 RetLoc1 / RetLoc2 / Main | 形参 n, A, B, C]`。当内层 `Hanoi(n-1, A, C, B)` 返回时，明确高亮弹出栈顶后跳回上层记录中的 `RetLoc1`（紧接着执行 `move(A, n, C)`）还是 `RetLoc2`（函数返回上一级）！
  3. **递归调用树（左下）**：随深度优先递归动态点亮当前活跃分支节点与已返回子树，统计总移动步数 $2^n - 1$。

### 3.3 `ch3_queue_sq_link` — 循环队列防假溢出与带头节点链队（算法 3.11～3.19）
- **教材锚点**：顺序队列假溢出问题分析；循环队列 `SqQueue`（算法 3.11～3.15，少用一空间判满）；带头节点链队 `LinkQueue`（算法 3.16～3.19）。
- **核心设计细节**：
  1. **「线性假溢出模式 vs 极坐标圆环循环队列」一键切换**：线性模式下演示连续入队出队后 `rear == MAXQSIZE` 而前端 `[0..2]` 空着却报上溢的“假溢出”窘境；切换为圆环模式后展示 `(rear + 1) % MAXQSIZE` 顺时针绕回，明确用斜线扇区标识「少用一个元素空间」以区分队空 `front == rear` 与队满 `(rear + 1) % MAXQSIZE == front`。
  2. **链队出队陷阱高亮（算法 3.18）**：当队中只剩最后一个节点且被删除时，`Q.front->next = p->next` 后头节点已为空，`Q.rear` 仍指向即将 `delete` 的 `p`！动画必须慢动作高亮 `if (Q.rear == p) Q.rear = Q.front;` 把尾指针拉回头节点防悬空。

### 3.4 `ch3_cases_expr_dance` — 栈与队列四大教材案例实验室（算法 3.20～3.23）
- **算法 3.20 数制转换**：十进制 $N$ 不断 `% d` 压栈、`N = N / d`，然后逐一弹栈逆序拼接输出 2/8/16 进制。
- **算法 3.21 括号匹配检验**：输入如 `[( )[( )[ ] ] ]`，顺序栈压入左括号，遇到右括号弹出栈顶配对；配对失败支持区分「左括号冗余（栈非空结束）」「右括号冗余（匹配时栈空）」「左右类型不符」三种报错高亮。
- **算法 3.22 算符优先表达式求值（核心重头戏）**：
  - 界面内嵌交互式 **教材表 3.1 `7×7` 算符优先关系矩阵**（必须按如下精确关系表编码进常量中）：
